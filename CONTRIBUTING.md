# Contributing to OpenCook

OpenCook is a cooking agent with a terminal interface. Work on cooking conversations, recipe workflows, knowledge retrieval, guided cooking, model configuration and kitchen devices is welcome.

Install Bun 1.4.2 and Node.js, then run `bun install` and `bun run dev --standalone` from the repository root. Follow AGENTS.md and the package guides. Run `bun run check` and the tests relevant to your changes. Protocol changes require `bun run generate`.

Use your own API credentials in the settings interface. Keep credentials, local configuration, captured kitchen data and database files out of commits. Preserve the copyright and attribution in LICENSE and NOTICE.
