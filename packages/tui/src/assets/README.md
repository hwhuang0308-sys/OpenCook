# Cooking display font

`unifont.json` embeds the unchanged GNU Unifont 16.0.04 BMP bitmap font as a Base64-encoded gzip stream. It is used to draw large Chinese cooking instructions with ordinary terminal block characters, without system font installation or a network request at runtime.
